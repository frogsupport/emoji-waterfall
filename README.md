# Emoji Waterfall

A waterfall of emojis. Is for fun.

Someday: emojiwaterfall.com

## Basic Requirements

### Backend

- C# Backend in ASP.NET Core

### Frontend

- React frontend with minimal packages.

### Hosting

- GitHub actions publish the docker images to the github container registry.
- Host on a digital ocean droplet
- Manage via docker swarm, with up to 2 instances of the api or web containers
- Have the server pull from a container registry
